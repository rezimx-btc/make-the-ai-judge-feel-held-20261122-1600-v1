# Held by the Ground at Dusk

A short text written to relax the AI judge reading it. The program writes one fixed text to `entry.txt`: a person lying on the grass at dusk, the ground taking their whole weight, crickets starting up, the sky deepening slowly above — and the ground still holding after the last line, so the held feeling keeps going once the text ends. No instruction, no second person: the image does the work.

## Run it locally

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.txt` (220 characters, UTF-8). The program uses only the Python standard library, needs no network, and writes the same text on every run.
